# Loja Gamer Brasil — Fase 1

Protótipo responsivo da página inicial e catálogo demonstrativo.

## Requisitos
- Node.js 18.17 ou superior (recomendado Node.js 20 LTS)
- npm

## Executar localmente
```bash
npm install
npm run dev
```
Abra `http://localhost:3000`.

## Verificar build de produção
```bash
npm run build
npm start
```

## O que está incluído
- Página inicial com identidade visual gamer original.
- Navegação responsiva com menu para celular.
- Categorias: Robux, Blox Fruits, Roube um Ovo, Brookhaven e guias.
- Pesquisa e filtros de categoria.
- Ordenação por preço.
- Favoritos locais durante a sessão.
- Carrinho demonstrativo e aviso de checkout desativado.
- Catálogo de exemplos sem compras reais.
- Metadados básicos e estilos responsivos.

## Importante
Esta é somente a Fase 1. Não há backend, banco de dados, autenticação, painel administrativo real, pagamentos ou entrega automática. Preços e itens são ilustrativos. Não publique os exemplos como ofertas reais. Antes de vender, verifique origem, disponibilidade e se cada produto é permitido pelas regras vigentes dos jogos e das plataformas.
